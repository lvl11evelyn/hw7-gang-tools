# HW Gang Tools Suite

A collection of HoboWars 1 tools designed to make routine gang administration faster and less error-prone.

## Included Components

### 1. Gang Incentives and Loans Aid (GILA)

Assists gang staff with incentive payouts and loan management.

Features include:

* Saving eligible recipients from Gang Board threads
* Recognizing supported milestone and Mining Union claims
* Preparing gang-loan payout information
* Tracking payouts through the native gang-loan workflow
* Reconciling completed transfers with HoboWars loan records
* Saving a reusable paid-post editing preset
* Recording visible member statistics from the Gang Members page

Existing GILA data is retained under its original browser-storage keys.

### 2. GP Awake Exporter

Adds an **Export GP Awake** button above the Awake standings table on the Gangsters Paradise gang page.

The generated text file includes:

* HoboWars `[hoboname=ID]` tags
* Aligned Awake values
* Total hobo count
* Total Awake
* A filename dated to the applicable Wednesday using server time

## Installation

A userscript manager such as [Tampermonkey](https://www.tampermonkey.net/) is required.

**[Install HW Gang Tools Suite](https://github.com/lvl11evelyn/hw7-gang-tools/raw/refs/heads/main/HW%20Gang%20Tools%20Suite.user.js)**

## Settings

Open the HoboWars **Preferences** page and select the **Gang Tools** tab.

Each component can be enabled or disabled independently. Each component is enabled by default.

## Storage and Privacy

Gang Tools stores its settings locally in your browser. The suite does not transmit data.

Removing the userscript does not remove its stored data.

## Updates and Issues

Updates are delivered automatically.

Bug reports and feature requests can be submitted through the [Issues page](https://github.com/lvl11evelyn/hw7-gang-tools/issues).

When reporting a problem, please include:

* The version
* The affected component
* The HoboWars page or action involved
* Any relevant browser-console messages
